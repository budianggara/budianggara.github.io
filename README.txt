Cara upload ke JagoWeb:
1. Login ke Control Web Panel.
2. Buka File Manager.
3. Masuk ke public_html (atau folder web utama yang diberikan hosting).
4. Upload index.html, style.css, script.js dan folder assets beserta isinya.
5. Pastikan index.html berada langsung di folder web utama.
6. Buka domain/subdomain Anda.
